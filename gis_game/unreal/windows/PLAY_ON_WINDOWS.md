# Play Goat Island Skiff on Windows

This ZIP contains the complete 64-bit Windows test build of the Unreal game. You do not need Unreal Engine or Blender to play.

1. Download `Goat-Island-Skiff-Windows.zip`.
2. In File Explorer, right-click the ZIP and choose **Extract All**.
3. Open the extracted **Goat-Island-Skiff-Windows** folder and double-click **GISGame.exe**.

Keep the entire extracted folder together. The `GISGame.exe` file alone is not the whole game. There is no installer or administrator setup step.

This test build is not digitally signed, so Windows SmartScreen may ask you to confirm before it starts. Check that you downloaded it from the Goat Island Skiff link on the Lab page before choosing to run it.

Use a 64-bit Windows PC with a graphics card and current graphics driver. If Windows reports a missing Visual C++ runtime DLL, install Microsoft's [latest supported Visual C++ Redistributable for x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist) and try again.

## Controls

- Hold the left mouse button and drag to move the tiller. The bow turns the opposite way while sailing ahead.
- Scroll the mouse wheel to trim or ease the sail.
- Press **M** for the lake map, **V** to switch camera, and **Esc** for settings or to quit.

This is a test build. It has been packaged and rendered on Windows, but a full interactive sailing session has not yet been verified. It is a sailing game, not a navigation chart; lake depths, hazards, live water levels, and bridge clearances are not verified.
